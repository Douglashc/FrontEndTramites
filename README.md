# FrontEndTramites

Frontend SPA para interactuar con la API de trámites municipales. Construido con Angular 18, Tailwind CSS 3, standalone components y lazy-loaded routes.

## Tecnologías

- Angular 18.2.x
- Tailwind CSS 3.4.x
- TypeScript 5.5.x
- SCSS
- RxJS 7.8.x

## Requisitos previos

- Node.js 18.x o superior
- npm 9.x o superior
- Backend corriendo en `http://localhost:5213`

## Ejecución

```bash
npm install
ng serve
```

El frontend estará disponible en `http://localhost:4200`.

## Servidor de desarrollo

Ejecuta `ng serve` para iniciar un servidor de desarrollo. Navega a `http://localhost:4200/`. La aplicación se recargará automáticamente si modificas archivos fuente.

## Build

Ejecuta `ng build` para compilar el proyecto. Los archivos generados se guardarán en el directorio `dist/`.
